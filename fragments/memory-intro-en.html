The series closes on persistence: Hermes runs two memory tracks in parallel. Fact memory flows through MemoryManager to on-disk files like MEMORY.md; session memory lives in SessionDB with an FTS5 index (including CJK) so session_search can recall across past conversations. The rest of the chapter walks those paths, the concurrency guards that keep atomic writes from clobbering external edits, and the optional community provider post-cortex when you want typed records and semantic recall on a daemon you host.
