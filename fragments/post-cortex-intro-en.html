Hermes ships built-in long-term memory — MEMORY.md facts and SessionDB FTS5 search (see Part 4 of the architecture series). post-cortex is a separate, community memory provider: a Hermes plugin plus a self-hosted daemon that stores typed records in an entity graph with local semantic search. Data stays on machines you control (RocksDB or SurrealDB, local embeddings). This article is a standalone deep dive — not a fifth chapter in the four-part gateway series.
